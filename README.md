# Soccer Slime

Browser-based Soccer Slime game with online multiplayer using PeerJS.

## Run locally

Open `index.html` in a browser, or use VS Code with the Live Server extension for a local development server.

## GitHub Pages

Upload this folder to a GitHub repository and enable GitHub Pages using the `main` branch and `/ (root)` folder.
Use git add .; git commit -m "Updated website"; git push to update website.
